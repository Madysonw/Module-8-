# Module-8-

What was the problem you were solving in the projects for this course?
For this course, I was working on creating a program that could organize and display course information for computer science students. The program needed to read information from a file, put the courses in alphanumeric order, and show what prerequisites were needed for certain classes. In Project One, I looked at different data structures like vectors, hash tables, and binary search trees to figure out which one would work best. Then, in Project Two, I took what I learned and used it to build the actual program.

How did you approach the problem? Consider why data structures are important to understand.
I started by breaking everything down into smaller parts so it wouldn't feel so overwhelming. I looked at how each data structure worked and compared things like memory usage, speed, and how well they could organize the course information. One thing I learned is that there isn't always just one way to solve a problem. Some ways might work better than others depending on what you're trying to do. Understanding data structures helped me see why it's important to think about how a program is going to work before jumping straight into writing the code.

How did you overcome any roadblocks you encountered while going through the activities or project?
I definitely ran into a few challenges along the way, especially when it came to understanding how the different data structures worked and how they affected the program. Getting everything to read from the file and display correctly also took some figuring out. When I got stuck, I went back through the course materials, looked over my code, and tried working through one problem at a time. Sometimes it took a few tries to get things right, but I learned that being patient and testing different things makes a big difference. It also helped me get a little more comfortable with debugging instead of getting frustrated when something didn't work the first time.

How has your work on this project expanded your approach to designing software and developing programs?
This course helped me look at programming a little differently. Before, I was mostly focused on just getting my code to work and making sure the output was right. Now I realize there's a lot more that goes into it. You have to think about how everything is organized, how efficiently it runs, and whether there's a better way to accomplish the same thing. These projects showed me that taking the time to plan things out can actually save a lot of trouble later. I feel like I'm starting to understand more of the reasoning behind how programs are designed instead of just focusing on the code itself.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
I think one of the biggest things I've taken away from this course is how important it is to keep my code organized and easy to understand. I've learned that using clear variable names, breaking things into functions, and not making everything more complicated than it needs to be can really help. It makes finding mistakes easier and also makes it less stressful if I need to go back and change something later. I'm still learning and figuring things out as I go, but I feel like I'm getting better at thinking ahead when I write my programs. I want to keep building on that so my code isn't just something that works, but something I can actually understand and improve later.
